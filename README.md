# Reel Recorder

Record Instagram reels on your phone with a teleprompter over the camera.

Open https://umesh581.github.io/reel-recorder/ on your phone, allow camera and microphone, then use **Add to Home Screen**.

- Add your Claude API key once (Prompter → Claude API key). The app writes 3 fresh Tenglish scripts every day, with real numbers and a CTA, or writes one from your own idea under **Ideas**.
- Or open a script from Content Machine's **Record** button.
- Tap the red button: 3-2-1, then it records while the script scrolls.
- Tap again to stop, review, and **Save to phone**.

Your API key and scripts stay on your phone. Scripts are written by calling the Claude API directly from your phone.
